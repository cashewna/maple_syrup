# Domain Glossary (`maple-gpui`)

Canonical vocabulary for the cleanroom Maple-inspired Computer Algebra System (CAS) and GPUI Worksheet. All module names, structs, tests, and UI labels follow these definitions.

- **`Rational`**: Exact reduced fraction `num / den` (`i128` numerator, `i128` positive denominator `den > 0`, `gcd(|num|, den) == 1`) used to preserve exact symbolic arithmetic without IEEE-754 floating-point drift.
- **`Expr`**: Immutable symbolic Abstract Syntax Tree (AST) node representing mathematical values and operations: `Rational`, `Float`, `Symbol`, `UnaryNeg`, `Add`, `Sub`, `Mul`, `Div`, `Pow`, `Call`, `Equation`, `Inequality`, `Range`, `List`, and `Matrix`.
- **`Inequality` & `RelOp`**: Symbolic relational comparison (`<`, `<=`, `>`, `>=` / `Lt`, `Le`, `Gt`, `Ge`) supporting chained compound bounds (`a < b < c` desugared to `And(...)`), interval/ray `solve` solutions (`And`, `Or`), and 2D/LaTeX display (`≤`, `≥`).
- **`Statement`**: Parsed Maple worksheet command terminated optionally by `;` (display output) or `:` (suppress output): `Assignment` (`:=`), `FunctionDef` (`x -> expr` or `(x, y) -> expr`), `EvalExpr`, or `Restart`.
- **`Environment`**: Stateful evaluation context storing bound symbolic variables, user-defined arrow functions (`FunctionDef`), and Maple-style history registers `%` (last output) and `%%` (penultimate output).
- **`Simplifier`**: Canonical algebraic normalizer performing exact `Rational` folding, additive/multiplicative identity elimination, like-term combination, Gaussian complex `I` arithmetic (`Re`, `Im`, `conjugate`, `I^n`), polynomial expansion (`expand`), univariate polynomial factorization (`factor`), rational normalization (`normal`), substitution (`subs`), and floating-point approximation (`evalf`).
- **`CalculusEngine` & `OdeSolution`**: Symbolic calculus evaluator supporting arbitrary-order differentiation (`diff`, including `x$n` notation), symbolic indefinite & definite integration (`int`), L'Hôpital-capable limits (`limit`), Taylor/Maclaurin series expansion (`series` / `taylor`), partial fraction decomposition (`convert(..., parfrac, x)`), finite/symbolic summations (`sum`), equation & inequality solving (`solve`), and ordinary differential equation solving (`dsolve`, `OdeSolution` for 1st/2nd-order linear ODEs with optional initial conditions).
- **`LinearAlgebraEngine`**: Exact rational/symbolic matrix processor supporting 1-based Maple matrix indexing `A[i, j]`, `Matrix`, `det` / `Determinant`, `Transpose`, `Inverse`, `rref` / `ReducedRowEchelonForm`, `trace`, `Rank`, `NullSpace`, characteristic-polynomial `Eigenvalues` up to 5x5, and `Eigenvectors`.
- **`PlotSeries`, `PlotData`, & `Plot3dData`**: Sampled 2D curve data (`name`, `(f64, f64)` points, domain `x_min..x_max`, computed range `y_min..y_max`) and sampled 3D scalar surface mesh data (`Plot3dData`, `grid` of `(x, y, z)` vertices) rendered interactively on GPUI canvases.
- **`DEplotTutor` & `StudyGuide`**: Cleanroom interactive Maple Education workflows (`src/tutor.rs`): `DEtools[DEplot][interactive]` phase-portrait direction-field & RK4 ODE integrator (`DePlotScene`) and interactive `StudyGuideChapter` / `HelpArticle` lessons (including Precalculus Ch. 1: Solving Inequalities).
- **`Worksheet` & `WorksheetCell`**: Ordered log of evaluated `[>` worksheet cells pairing input text, `CellOutput` (`Text`, `MatrixGrid`, `Plot`, `Plot3d`, `Suppressed`, `Error`), execution latency (`elapsed_us`), in-place cell editing (`update_cell`), and `.mpl`/`.mw` file loading (`load_file`).
- **`Workbook` & `WorksheetTab`**: Collection of open document tabs (`Start.mw` landing page plus one or more interactive `.mw` `Worksheet` sessions) with an active tab index.
- **`PaletteSection`**: Collapsible left-dock accordion category (`Expression`, `Calculus`, `Variables`, `Matrix`, `Common Symbols & Greek`) exposing clickable Maple templates and live kernel symbols.
- **`MatrixTemplate` & `MatrixPresetKind`**: Configurable row/column (`1..=6`) generator producing `Matrix([[...]])` expressions in `Zero`, `Identity`, `Sequential`, or `Symbolic` presets.
- **`ContextAction`**: One-click right-dock operation derived from a selected or latest `WorksheetCell` output (e.g., `Determinant`, `Inverse`, `RREF` for matrices; `Differentiate`, `Integrate`, `Simplify`, `Plot 2D` for expressions).
